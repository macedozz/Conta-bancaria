Simulador de Conta Bancária 
-
Este projeto é uma simulação interativa de uma conta bancária via terminal, desenvolvida em Java. O programa foi construído como solução para um dos desafios práticos da trilha de programação Java da Alura.

Funcionalidades
-
O sistema permite ao usuário inicializar sua conta com seus dados básicos e, em seguida, acessar um menu interativo com as seguintes operações:

Cadastro Inicial: Inserção do nome, tipo de conta e saldo inicial.

Consultar Saldo: Exibe o saldo atualizado da conta.

Receber Valor: Adiciona um valor especificado ao saldo da conta.

Transferir Valor: Subtrai um valor do saldo da conta, com validação de segurança para impedir transferências caso não haja saldo suficiente.

Sair: Encerra a aplicação.
